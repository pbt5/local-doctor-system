# local-doctor-system

This repo is a multi-platform (e.g., Linux, Windows, macOS) desktop application written in Python to provide functionality to our smart pill box device. It allows a trusted health care provider (HCP) or personal associate to program medication schedules and monitor adherence data from the smart pill box. The application communicates with the smart pill box via WiFi and provides a user-friendly interface for managing medication schedules and viewing adherence data.
